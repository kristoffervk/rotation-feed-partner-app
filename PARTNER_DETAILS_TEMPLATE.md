# Details to send Rotation

Copy this list, fill it in, and send it to your Rotation contact. Steps refer to `README.md`.

**Send the Client secret only privately** (a direct message to your Rotation contact, or a one-time password-manager link). Never in a shared or public channel, a group email thread, a screenshot or a Git repository.

```text
Company / store name:
Contact person (name, email):
Preferred language (English, Norwegian, Swedish or Finnish):

1. Store address (ends in .myshopify.com; Shopify admin > Settings > Domains):

2. Install link (step E), or "installed from the Installs card":

3. Client ID (Dev Dashboard > Rotation Feed > Settings; 32 characters):

4. Client secret (same page)  -> send PRIVATELY, see above

5. Done? (yes / no)
   - shopify app deploy released a version (step D):
   - the app is installed on the store (step F):
```

The Client ID and the install link are not secret. The Client secret is: if it leaks, rotate it in the Dev Dashboard and send Rotation the new one privately.
